Personal, locally operated application

Novel Studio

About the application

Novel Studio is a personal, locally operated application for assisting with novel writing and managing related project data.

The application can connect to Google Drive and Google Sheets only when authorized by the user. Google Drive / Sheets access is used for the user's own novel-production data, including data needed to load and manage a local project.

Novel Studio is currently intended for personal use. Google user data is not sold, is not used for advertising, and is not provided to unrelated third parties. Authentication credentials are used only for the application's Google API access authorized by the user.

アプリケーションについて

Novel Studio は、小説制作および関連データ管理を支援する個人利用向けの ローカルアプリケーションです。

ユーザー自身が明示的に許可した場合にのみ Google Drive / Google Sheets へ接続します。 Google Drive / Sheets へのアクセスは、ユーザー自身の小説制作データをローカルの プロジェクトへ読み込み、管理するために使用します。

Google ユーザーデータを販売せず、広告目的にも利用せず、無関係な第三者へ提供しません。 認証情報は、ユーザーが許可した Google API アクセスのためだけに使用します。
