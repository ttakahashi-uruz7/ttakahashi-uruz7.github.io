Novel Studio

Privacy Policy

Last updated: 2026-09-08

1. Purpose

Novel Studio is a personal, locally operated novel-production application. It is currently intended for personal use and is not offered as a general-purpose commercial SaaS service.

2. Google API access

The application may access Google Drive and Google Sheets after the user explicitly authorizes that access through Google OAuth. The application does not access a Google account without that authorization.

3. Data used

Depending on the requested local workflow, the application may use:

  • Google Drive file metadata needed to identify a project source;
  • text exported from Google Docs used as manuscript or project source data;
  • Google Sheets values used as structured novel-production data; and
  • data needed to load, synchronize, organize, or manage the user's local project data.

Google Workspace access depends on the workflow requested by the user. Baseline and Master sources are read for reference. When the user explicitly requests a Working Reset, the application may write to the Working Test Dataset, including deleting selected Working files or folders, creating folders, and copying source data. The application does not perform ordinary writes to Production sources as part of its normal workflows. It does not claim that every possible Google service or data type is used.

4. Purpose of use

Google API data is used only for functions explicitly requested by the user, including loading and managing the user's own novel-project data and carrying out a requested Working Reset. Any Working Test Dataset deletion, folder creation, or copy operation is performed only as part of that requested workflow.

5. Data sharing and limited use

Google user data is not sold, is not used for advertising, and is not provided to unrelated third parties. Google API data is used only to provide the application functions described in this policy and at the user's request.

6. Local processing and storage

Novel Studio is primarily operated locally. OAuth credentials, tokens, and application data may be stored locally as required for application operation. The exact local storage mechanism depends on the application's configuration and may change as the application develops. This policy does not promise a particular operating-system credential store.

7. Revoking access

The user can revoke Novel Studio's access at any time from the Google Account settings for connected apps and services. The user may also remove local application data and settings from the device where the application is operated.

8. Data retention

Data and settings stored locally may be retained until the user removes them or uninstalls or resets the relevant local application data. Google retains data in accordance with Google's own policies and the user's Google Account settings.

9. Contact

For public project information or questions, use the public GitHub repository or the associated GitHub profile. No private email address is published on this site.
